# Morocco Bac+2 Developer Recovery Roadmap (2026)

## Profile Target
This roadmap is designed for:
- Someone who studied development around 2020
- Forgot most technical concepts
- Wants to pass Moroccan IT competitive exams (concours)
- Wants to become employable again in Morocco

---

# Main Objectives

By the end of this roadmap, you should be able to:

- Pass Bac+2 IT concours in Morocco
- Rebuild strong computer science fundamentals
- Build real projects again
- Understand modern development workflows
- Be ready for internships/jobs/interviews

---

# Total Duration

Recommended duration:

- Intensive mode: 4–6 months
- Normal mode: 6–9 months

Minimum recommended study time:

- 2–3 hours/day if busy
- 5–6 hours/day if full-time learning

---

# Global Strategy

The roadmap follows this order:

1. Rebuild computer science fundamentals
2. Relearn programming deeply
3. Learn SQL and algorithms
4. Build projects
5. Learn frameworks
6. Prepare specifically for concours
7. Simulate interviews and exams

---

# Final Advice

Do not think:

> “I forgot everything.”

Think:

> “I already learned these concepts once.”

Relearning is dramatically faster than learning from zero.

Most former development students can recover strong technical fundamentals within 4–6 months with consistent daily practice.
